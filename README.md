# rocky

Keeps what you write and notices when you go quiet.

One self-contained HTML file. No build step, no dependencies, no server, no
account, no analytics, and no network requests of any kind. Your record is kept
in your own browser on your own device.

It does not know how you feel, does not read what you write, does not compare you
to anyone, does not diagnose you, does not detect a crisis, and does not send
anything anywhere. The page itself carries the full list.

Live at the Pages URL for this repository. `index.html` is the whole product.
